# 빌드 가이드

원거리에서 적을 꿰뚫는 뇌격, 낙인과 폭발을 연계하는 잿불, 무기 피해에 집중하는 강철 중 자신의 전투 방식에 맞는 빌드를 골라 보세요. 아래 배분은 출발점이며, 획득한 장비에 맞춰 거점에서 조정할 수 있습니다.

## 공통 원칙

### 능력치

| 능력치 | 권장 |
| --- | --- |
| 힘 | 쓰고 싶은 무기·갑옷의 힘 요구치까지만. 물리 피해 +1%/점은 덤 |
| 민첩 | 세검을 쓸 때만 요구치까지. 아니면 0~레벨만큼 |
| 활력 | **나머지 전부**. 1점 = 생명 3 |
| 정신 | 0. 1점 = 의지 1, 원소 피해 0.5%로 활력보다 효율이 낮음 |

- 장비 요구치는 장비로 얻은 힘·민첩도 포함하므로, 힘 옵션이 붙은 반지·허리띠를 끼면 그만큼 포인트를 아낄 수 있습니다.
- 거점에서 무료 재분배가 되므로, 더 좋은 무기를 주웠다면 힘을 다시 맞추면 됩니다.

| 목표 무기 | 필요한 힘 | 기본 20에서 넣을 포인트 |
| --- | --- | --- |
| 기사검 | 25 | 5 |
| 처형인의 대검 | 40 | 20 |
| 성기사 장검 | 55 | 35 |
| 잿불 대검 | 85 | 65 |
| 성흔 장검 | 90 | 70 |
| 뇌정 대검 | 130 | 110 |

### 저항

난도 패널티 때문에 저항이 가장 흔한 사망 원인입니다.

| 난도 | 패널티 | 장비로 채울 목표 | 실제 저항 |
| --- | --- | --- | --- |
| 순례 | 0 | 신경 쓰지 않아도 됨 | - |
| 고행 | −20 | 화염·번개 각 50% | 30% |
| 순교 | −40 | 화염·번개 각 90% 이상 | 50% 이상 |

모든 저항 옵션(무지갯빛·찬란한, 금강석 방어구, 별·종언 룬)이 두 저항을 한꺼번에 올려 효율이 좋습니다.

### 장비 우선순위

1. 무기 피해(강화 피해, 추가 피해) — 원형 참격과 기본 검격의 기반
2. 화염·번개 저항
3. 최대 생명, 활력
4. 주력 기술 원소 피해%와 +기술
5. 공격 속도, 생명 흡수
6. 마법 아이템 발견(순교에서 파밍할 때)

빈 장비 칸부터 채우세요. 투구·장갑·장화·허리띠의 방어와 옵션도 생존에 도움이 됩니다.

## 뇌격 빌드 (번개 투척 주력)

일렬로 몰려오는 적을 번개 구체로 꿰뚫고, 근접에서는 검격 3회마다 연쇄 번개가 터집니다.

### 기술 칸

| 칸 | 기술 |
| --- | --- |
| 칸 1 (우클릭) | 원형 참격 |
| 칸 2 (Q) | 천둥 강림 (레벨 24부터, 그 전엔 화염 낙인) |
| 칸 3 (R) | 번개 투척 (레벨 12부터) |

### 포인트 순서

| 캐릭터 레벨 | 투자 |
| --- | --- |
| 2~5 | 신속한 손 |
| 6~11 | 뇌격 위주 + 신속한 손 |
| 12~17 | **번개 투척 2 : 뇌격 1** |
| 18~23 | 번개 투척 + 폭풍 전도 |
| 24 이후 | 번개 투척 > 뇌격 > 천둥 강림 > 폭풍 전도 > 신속한 손 |

### 레벨 33 구성 예시

획득한 장비와 옵션에 따라 최종 수치는 달라집니다.

| 항목 | 값 |
| --- | --- |
| 능력치 투자 | 힘 76, 민첩 19, 활력 65, 정신 0 |
| 기술 | 신속한 손 5, 뇌격 8, 번개 투척 14, 폭풍 전도 5, 천둥 강림 3 (+ 시작 기술 2) |
| 생명 / 방어 | 567 / 224 |
| 물리 피해 / 공속 | 48~113 / 1.23 |
| 번개 투척 피해 | 147~334 |
| 화염·번개 저항(순교 적용) | 39 / 43 |
| 무기 | 성흔 장검(일반, 전설형) |

### 핵심 장비

- 폭풍 사도(고유 검, 뇌격 +2), 폭풍의 눈(고유 부적, 뇌격 검술 +2)
- 뇌정 순례단 세트(완성 시 모든 기술 +1, 공속 20%)
- 빛의 혀 룬워드(빛 + 숨 + 혼, 3소켓 검)
- 접미 '폭풍의', '정전의'(번개 피해%), 접두 '뇌우 견습생의·기사의'

### 운영

- 사수는 영웅이 5m 안에 오면 물러납니다. 번개 투척은 관통이라 사수를 쫓아갈 필요가 없습니다.
- 의지가 모자라면 기본 검격으로 채우세요. 한 번 휘두를 때 최대 12가 찹니다. 가만히 있어도 30초면 가득 찹니다.
- 뇌격은 기본 검격 적중으로만 쌓입니다. 근접 무리에는 좌클릭을 누른 채로 R을 섞어 쓰세요(공격 중 누른 기술은 0.5초 동안 기억됩니다).

## 잿불 빌드 (화염 구체 + 파열)

화염 구체로 무리에 낙인을 찍고, 검격으로 잔불을 쌓은 뒤 원형 참격으로 터뜨려 파열을 번지게 합니다.

### 기술 칸

| 칸 | 기술 |
| --- | --- |
| 칸 1 (우클릭) | 원형 참격 |
| 칸 2 (Q) | 화염 낙인 |
| 칸 3 (R) | 화염 구체 (레벨 12부터) |

### 포인트 순서

| 캐릭터 레벨 | 투자 |
| --- | --- |
| 2~5 | 화염 낙인 |
| 6~11 | 파열 위주 + 화염 낙인 |
| 12~17 | **화염 구체 2 : 파열 1** |
| 18~23 | 화염 구체 + 잿불 숙련 |
| 24 이후 | 화염 구체 > 파열 > 잿불 숙련 > 화염 낙인 > 재의 장막 |

### 레벨 35 구성 예시

획득한 장비와 옵션에 따라 최종 수치는 달라집니다.

| 항목 | 값 |
| --- | --- |
| 능력치 투자 | 힘 50, 민첩 35, 활력 85, 정신 0 |
| 기술 | 화염 낙인 6, 파열 8, 화염 구체 15, 잿불 숙련 6, 재의 장막 3, 원형 참격 1 |
| 생명 / 방어 | 719 / 224 |
| 물리 피해 / 공속 | 38~99 / 1.00 |
| 화염 구체 피해 | 154~264 |
| 화염·번개 저항(순교 적용) | 75 / 75 (상한) |
| 무기 | 명장의 성기사 장검(마법, 정예형) |

### 핵심 장비

- 잿불 성인의 대검(고유, 파열 +2, 잿불 파열 +1), 타오르는 심장(고유 부적, 잿불 파열 +2)
- 재의 서약자 세트(3부위에 잔불 최대 +1, 완성 시 화염 피해 30%)
- 불씨 맹세 룬워드(불씨 + 잿, 2소켓 검) — 레벨 1부터 가능, 화염 낙인 +1
- 접미 '화염의', '불씨의'(화염 피해%), 접두 '잿불 견습생의·기사의'

### 운영

- 화염 구체가 맞힌 적에게 4초 낙인이 남습니다. 구체 → 검격 2~3회 → 원형 참격 순서로 쓰면 파열이 크게 터집니다.
- 파열은 같은 적을 한 번만 때리므로, 잔불을 여러 적에게 고르게 쌓는 편이 좋습니다.
- 재의 장막 10레벨에서 잔불 최대 누적이 7로 늘어납니다.
- 고행 진입 전에 화염·번개 저항을 먼저 맞추세요. 원거리 기술을 쓰더라도 원소 공격에 대비해야 합니다.

## 강철 근접 빌드 (응용 구성)

원형 참격과 기본 검격의 물리 피해로 싸우는 근접 빌드입니다. 무기와 생존 장비에 크게 영향을 받는 응용 구성입니다. 모든 난도 완주를 보장하는 구성은 아니므로 장비가 갖춰진 뒤 도전하세요.

### 구성

| 레벨 | 투자 |
| --- | --- |
| 2~5 | 원형 참격 |
| 6~11 | 강철 피부, 원형 참격 |
| 12~17 | 전투 함성 1 + 원형 참격 |
| 18~23 | 피의 갈증 |
| 24 이후 | 원형 참격 > 불굴 > 피의 갈증 > 전투 함성 > 강철 피부 |

- 원형 참격 20레벨은 무기 피해 270%, 전투 함성 20레벨은 물리 피해 +140%입니다.
- 무기 피해가 전부이므로 대검(뇌정 대검 32~72)과 강화 피해가 큰 고유·룬워드(종언의 맹세, 피의 순례, 종언의 서약)를 노립니다.
- 원소 피해가 없으므로 '철갑' 정예(물리 50% 감소)가 가장 어렵습니다. 장비의 화염·번개 추가 피해로 보완하세요.
- 잿불 트리의 화염 낙인·파열을 조금 섞으면 원형 참격에 잔불 화염 피해가 붙습니다.
