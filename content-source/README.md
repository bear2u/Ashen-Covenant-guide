## 용어

| 용어 | 뜻 |
| --- | --- |
| 거점 | 꺼지지 않는 성화. 상인·보관함·제단·출정문이 있는 안전 지대 |
| 난도 | 순례(1) · 고행(2) · 순교(3) |
| 의지 | 기술을 쓰는 자원. D2의 마나에 해당 |
| 잔불 | 낙인 찍힌 적을 베면 쌓이는 표식. 원형 참격이 소비해 화염 피해와 파열을 일으킴 |
| 몬스터 레벨 | 방마다 정해진 레벨. 체력·피해·경험치·드롭 아이템 레벨을 결정 |
| 아이템 레벨 | 아이템이 떨어진 곳의 몬스터 레벨. 붙을 수 있는 옵션 등급과 소켓 수를 결정 |
| 품질 레벨 | 기반 장비마다 정해진 레벨. 이 레벨 이상의 아이템 레벨에서만 그 기반이 떨어짐 |
| 기반 | 장비의 바탕 종류(예: 성기사 장검). 기본형·정예형·전설형 3단계 |
| 등급 | 낡은·일반·우수·마법·희귀·세트·고유·제작·룬워드 |
| 하드 포인트 | 직접 투자한 기술 포인트. 장비 +기술은 포함하지 않음 |
