# 조작

## PC (키보드와 마우스)

| 입력 | 행동 |
| --- | --- |
| W A S D | 화면 기준 이동 |
| 마우스 | 조준. 캐릭터는 커서 쪽을 바라봅니다. |
| 좌클릭 (누르고 있기) | 기본 검격. 부채꼴 약 112°, 사거리 2.7m. 적중 시 의지 회복, 낙인 찍힌 적에게 잔불 1 누적 |
| 우클릭 | 기술 칸 1 (기본: 원형 참격) |
| Q | 기술 칸 2 (기본: 화염 낙인) |
| R | 기술 칸 3 (기본: 비어 있음) |
| Space | 회피. 무적 0.42초, 대기 2초(장비·기술로 최대 40% 감소) |
| F | 회복약. 최대 생명의 55% 즉시 회복, 탐험당 3개, 재사용 대기 0.6초 |
| E | 줍기 · 상자 열기 · 제단 · 상인 · 보관함 · 출정문 · 귀환문 |
| I | 장비 창. 가방의 장비를 **더블 클릭**하면 바로 장착, 마우스를 올리면 착용 중인 장비와 나란히 비교 |
| C | 능력치 창 |
| K 또는 P | 기술 창 |
| Esc | 창 닫기, 일시정지 메뉴(음량, 화면 흔들림, 그래픽 품질, 탐험 포기) |

### 입력 버퍼

검격 중에 누른 **Q·R·F**는 버려지지 않습니다. 휘두르기가 끝나면 0.5초 안에 발동합니다. 그래서 좌클릭을 누른 채 Q나 R을 눌러도 기술이 나갑니다. 0.5초가 지나면 입력은 사라집니다.

### 그 밖의 규칙

- 창이 열려 있거나 브라우저 창에서 포커스가 벗어나면 던전 시간이 멈춥니다.
- 마우스 버튼은 게임 화면(캔버스)에서 눌렀을 때만 공격으로 처리합니다. 창이나 버튼을 누르다가 공격이 나가지 않습니다.
- 바닥에 떨어진 아이템 이름표를 클릭해도 줍습니다.

## 휴대폰·태블릿 (터치)

| 터치 | 행동 |
| --- | --- |
| 왼쪽 화면 끌기 | 이동. 손가락이 닿은 곳에 가상 스틱이 생깁니다. |
| 큰 검 버튼 누르고 있기 | 가까운 적을 자동으로 겨냥해 다가가며 검격 |
| 기술 버튼 3개 | 기술 칸 1·2·3 |
| 회피 버튼 | 스틱 방향으로 회피. 스틱이 없으면 가까운 적에게서 멀어지는 쪽으로 |
| 물약 버튼 | 회복약 |
| 상황 버튼 | 줍기·상자·제단·상인·출정. 가까이 가면 나타납니다. |
| 바닥 아이템 이름 탭 | 줍기 |
| 장비 / 능력치 / 기술 / 메뉴 | 미니맵 아래 버튼. 쓸 포인트가 남아 있으면 주황 점이 붙습니다. |

### 자동 조준

검 버튼과 기술 버튼은 사거리 안의 살아 있는 적 중 가장 가까운 적을 노립니다. 이때 바라보는 방향 앞쪽에 있는 적은 최대 1.6m 더 가깝게 계산해서, 등 뒤의 적보다 앞의 적을 먼저 고릅니다. 깨어 있는 적이나 보스 중 시야(벽에 가리지 않음)에 있는 적만 대상이 됩니다.

### 스틱

- 손가락을 조금 움직였을 때 오작동하지 않도록 스틱 반지름의 18%까지는 무시합니다.
- 스틱 바깥까지 끌어도 최대 속도로 고정됩니다.

### 화면과 성능

- 카메라 거리는 화면 비율에 맞춰 자동 조절됩니다. 가로 휴대폰에서는 캐릭터를 크게, 세로에서는 좌우를 넓게 보여 줍니다.
- 그래픽 품질 기본값은 '자동'입니다. 2초 평균 45fps 아래로 떨어지면 한 단계 낮추고, 57fps 이상이 8초 이어지면 한 단계 올립니다. 메뉴에서 높음·중간·낮음으로 고정할 수 있습니다.

| 품질 | 해상도 배율 | 그림자 | 블룸 | 광원 | 재 입자 |
| --- | --- | --- | --- | --- | --- |
| 낮음 | 0.85 | 없음 | 없음 | 2 | 50 |
| 중간 | 1.25 | 1024 | 있음 | 3 | 100 |
| 높음 | 1.75 | 2048 | 있음 | 5 | 160 |

- 노치 안전 영역을 피해서 버튼을 배치했습니다. 핀치 확대, 더블탭 확대, 스크롤, 길게 누르기 메뉴는 막았습니다.
- 다른 앱으로 전환하면 자동으로 일시정지합니다.
- 휴대폰에서는 0.6배 크기의 스프라이트 아틀라스(`sprites/m/`)를 써서 메모리를 아낍니다.

## 기술 칸 바꾸기

**K**(기술 창)에서 액티브 기술을 고르고 칸 1·2·3 중 하나를 누릅니다. 배운 액티브 기술(하드 포인트 1 이상)만 지정할 수 있습니다. 같은 기술을 다른 칸에 지정하면 원래 칸은 비워집니다.

| 액티브 기술 | 트리 | 기본 칸 |
| --- | --- | --- |
| 원형 참격 | 강철 맹세 | 칸 1 (우클릭) |
| 화염 낙인 | 잿불 파열 | 칸 2 (Q) |
| 번개 투척 | 뇌격 검술 | - |
| 천둥 강림 | 뇌격 검술 | - |
| 화염 구체 | 잿불 파열 | - |
| 전투 함성 | 강철 맹세 | - |
