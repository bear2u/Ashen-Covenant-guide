# 저장과 이어하기

## 자동 저장

장비 획득·장착, 구매·판매, 레벨업, 포인트 배분, 구역 정화, 보스 처치, 사망과 귀환 등 주요 행동마다 진행 상황이 자동으로 저장됩니다. 별도의 저장 버튼은 없습니다.

## 이어하기

타이틀 화면에서 **이어하기**를 누르면 거점에서 시작합니다.

| 유지되는 것 | 다시 시작하는 것 |
| --- | --- |
| 레벨·능력치·기술, 장비·가방·보관함, 골드, 해금한 난도 | 진행 중이던 던전 |

## 저장이 보이지 않을 때

저장은 **플레이한 기기·브라우저·게임 주소**에 연결되어 있습니다. 다른 기기나 브라우저로 자동 동기화되지 않습니다.

1. 이전에 사용한 기기와 브라우저인지 확인하세요.
2. 이전에 플레이했던 게임 주소로 접속했는지 확인하세요.
3. 시크릿·비공개 창을 사용하지 않았는지 확인하세요. 해당 창을 닫으면 저장이 유지되지 않을 수 있습니다.

브라우저의 사이트 데이터를 삭제하면 저장도 사라집니다. 저장을 유지하려면 게임의 사이트 데이터를 지우지 마세요.

## 새 게임을 시작할 때

저장이 이미 있으면 **새 게임**을 한 번 눌렀을 때 덮어쓰기 안내가 나옵니다. 한 번 더 누르면 기존 진행을 덮어쓰고 레벨 1부터 시작합니다. 기존 캐릭터를 계속하려면 **이어하기**를 선택하세요.

## 저장 오류가 표시될 때

“저장 데이터가 손상되었거나 호환되지 않습니다”라는 안내가 나오면 이어하기가 제한됩니다. 이때 기존 저장은 그대로 보존됩니다.

- 기존 진행을 유지하려면 **새 게임을 다시 눌러 덮어쓰지 마세요**.
- 브라우저의 사이트 데이터를 삭제하지 마세요.
- 표시된 안내와 사용한 기기·브라우저를 기록해 두세요.

## 이전 버전에서 이어하기

성장 시스템 개편 전의 저장은 **이어하기**를 누르면 새 성장 체계로 옮겨집니다. 레벨·골드·해금 난도는 유지되며, 경험치는 초기화되고 예전 패시브는 능력치·기술 포인트로 돌아옵니다. 장비와 옵션도 새 체계에 맞게 바뀝니다.

이어하기 후에는 거점에서 **능력치·기술·착용 장비**를 확인하고 남은 포인트를 배분한 뒤 출정하세요.
