# 재의 성약 플레이어 가이드

Ashen Covenant의 조작법, 캐릭터 성장, 장비 도감, 빌드와 던전 공략을 제공하는 한국어 가이드입니다.

https://bear2u.github.io/Ashen-Covenant-guide/

이 저장소는 가이드 웹사이트만 관리합니다. 게임 소스나 개발 문서를 공개하는 저장소가 아닙니다.

## 문서 관리

- 공개용으로 편집한 `content-source/` 문서만 사용합니다.
- 게임 프로젝트의 내부 문서를 통째로 가져오지 않습니다.
- Node 24에서 `npm ci`, `npm run check`로 확인합니다.
- `main`에 반영하면 GitHub Pages에 배포됩니다.
