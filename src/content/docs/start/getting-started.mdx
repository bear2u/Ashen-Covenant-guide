## 게임 시작

게임 페이지를 브라우저에서 열고 **새 게임**을 선택하세요. 이전에 플레이한 기록이 있다면 **이어하기**로 거점에서 모험을 계속할 수 있습니다.

## 휴대폰에서 하기

1. 휴대폰 브라우저에서 게임 페이지를 엽니다.
2. 화면을 가로로 돌립니다. 세로 화면에서는 회전 안내가 표시됩니다.
3. 왼쪽 가상 스틱으로 이동하고 오른쪽 버튼으로 공격·기술·회피를 사용합니다.
4. 화면이 끊기면 메뉴에서 그래픽 품질을 낮춰 보세요.

자세한 터치 조작은 [조작](/start/controls/)을 확인하세요.

## 타이틀 화면

| 버튼 | 동작 |
| --- | --- |
| 새 게임 | 레벨 1 캐릭터로 시작합니다. 저장이 이미 있으면 버튼이 "기존 저장을 덮어씁니다 · 다시 눌러 확인"으로 바뀌고, 한 번 더 눌러야 시작합니다. |
| 이어하기 | 언제나 거점에서 시작합니다. 레벨·능력치·기술·장비·보관함·골드·해금 난도는 그대로이고, 진행 중이던 던전만 처음부터입니다. |

저장이 손상되었으면 이어하기가 막히고 원본은 그대로 남습니다. [저장과 이어하기](/help/save-data/)를 보세요.

## 첫 한 시간

### 1. 첫 출정 (레벨 1 → 약 14)

1. 새 게임을 누르면 거점에서 시작합니다. 북쪽 출정문으로 가서 **E**를 누르고 **순례**를 고릅니다.
2. 첫 던전에서는 조작 학습이 7단계로 나옵니다. 이동 → 검격 → 화염 낙인 → 잔불 쌓기 → 원형 참격 → 회피 → 회복약 순서이며, 건너뛸 수도 있습니다.
3. 첫 구역(잿빛 현관)의 적을 모두 처치하면 중앙의 **성물 제단**이 빛납니다. E를 눌러 둘 중 하나를 받습니다. 한 번만 받을 수 있습니다.
   - **뇌격의 순례자의 장검**: 뇌격 +1, 강화 피해 25%. 뇌격을 배우지 않아도 검격 3회마다 연쇄 번개가 나갑니다.
   - **파열의 부적**: 파열 +1, 화염 기술 피해 10%. 원형 참격으로 잔불을 터뜨리면 주변 적에게 파열 폭발이 번집니다.
4. 받은 장비는 가방에 들어갑니다. **I**(장비 창)를 열어 장착합니다.
5. 구역을 정화할 때마다 다음 성문이 열리고 골드를 받습니다. 6번째 구역 '지하 성소'의 보스 '재의 대주교'를 쓰러뜨리면 귀환문이 열립니다.

### 2. 레벨업하면

- 레벨이 오를 때마다 **능력치 5점**과 **기술 1점**을 받습니다. 화면 위에 배너가 뜨고, 장비·능력치·기술 버튼에 주황 점이 생깁니다.
- **C**(능력치): 처음에는 활력에 넉넉히, 더 좋은 무기를 들 만큼만 힘에 넣는 것이 무난합니다.
- **K**(기술): 레벨 6에 뇌격·파열·강철 피부가 열립니다. 어느 쪽으로 키울지는 [빌드 가이드](/builds/guide/)를 참고하세요.
- 던전 안에서도 포인트를 쓸 수 있습니다. 되돌리기(재분배)는 거점에서만 됩니다.

### 3. 첫 귀환 후 거점에서

1. **잿빛 수녀**(상인)에게 필요 없는 장비를 팝니다. 빠른 판매 탭에서 누르면 바로 팔립니다.
2. 상인 진열품 8개(일반 3, 마법 5)를 확인합니다. 귀환할 때마다 캐릭터 레벨에 맞춰 바뀝니다.
3. 골드가 남으면 **도박**으로 반지·부적을 노려 봅니다.
4. **성약의 제단**에서 보석 3개를 한 단계 위로 합칠 수 있습니다.
5. 순례를 클리어하면 **고행**이 열리고 기술 포인트를 1점 더 받습니다(난도별 첫 보스 처치 보상).

### 4. 다음 목표

| 레벨 | 목표 |
| --- | --- |
| 6 | 주력 트리의 6레벨 기술(뇌격 또는 파열) 배우기 |
| 12 | 주력 원거리 기술(번개 투척 또는 화염 구체) 배우고 기술 칸에 지정 |
| 15~18 | 고행 진입. 화염·번개 저항을 30% 이상 맞추기(고행은 저항 −20) |
| 18 | 폭풍 전도 또는 잿불 숙련으로 원소 피해 크게 올리기 |
| 25~30 | 순교 진입. 저항 50% 이상, 정예형 무기·갑옷으로 교체(순교는 저항 −40) |
| 30~40 | 고유·세트·룬워드 수집 |

진행 속도는 장비와 익숙함에 따라 달라집니다. 다음 난도가 버겁다면 이전 난도에서 장비를 보강한 뒤 다시 도전하세요.
