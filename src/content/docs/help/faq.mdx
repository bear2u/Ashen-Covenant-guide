## 실행

**주소를 열었는데 페이지가 안 떠요.**
개발 서버가 꺼져 있습니다. `AshenCovenant` 폴더에서 `npm run dev`(휴대폰도 쓰려면 `npm run dev:lan`)를 실행하세요. 터미널을 닫으면 서버도 꺼집니다.

**휴대폰에서 접속이 안 돼요.**
- `npm run dev`는 이 컴퓨터에서만 열립니다. `npm run dev:lan`으로 켜야 합니다.
- 휴대폰과 컴퓨터가 같은 Wi-Fi인지 확인하세요.
- 네트워크가 바뀌면 IP도 바뀝니다. `ipconfig getifaddr en0`으로 다시 확인하세요.
- macOS 방화벽이 Node 연결을 막고 있으면 허용해 주세요.

**`dist/index.html`을 더블클릭하면 검은 화면이에요.**
빌드 결과물은 HTTP 서버로 열어야 합니다. `npm run preview`를 쓰세요.

**PC에서 하던 저장이 휴대폰에 없어요.**
저장은 브라우저와 주소마다 따로입니다. `127.0.0.1`과 IP 주소로 연 것도 서로 다른 저장입니다.

## 조작

**좌클릭을 누른 채로는 기술이 안 나가요.**
지금은 나갑니다. 검격 중에 누른 Q·R·F는 0.5초 동안 기억했다가 휘두르기가 끝나면 발동합니다. 그래도 안 나가면 의지가 모자라거나 재사용 대기 중인지 확인하세요.

**창을 누르다가 공격이 나가요.**
마우스 버튼은 게임 화면에서 누를 때만 공격으로 처리합니다. 창 위에서 누른 클릭은 공격이 되지 않습니다.

## 진행

**방이 안 끝나요(성문이 안 열려요).**
구역 안에 남은 적이 있습니다. 미니맵에서 적을 찾아보세요. 영웅이 그 구역 안에 있고 깨어 있는 적이 하나도 없으면, 남은 적이 모두 깨어나 몰려옵니다.

**성물 제단이 안 빛나요.**
구역 1(잿빛 현관)을 정화해야 깨어납니다. 계정당 한 번만 받을 수 있어서, 이미 받았다면 다시 나오지 않습니다.

**죽으면 뭘 잃나요?**
아무것도 잃지 않습니다. 경험치·장비·골드가 모두 남고, 그 판의 던전 진행만 처음부터입니다.

**레벨이 올라도 경험치가 거의 안 들어와요.**
몬스터보다 레벨이 6 이상 높으면 경험치가 줄고, 10 이상이면 5%만 받습니다. 다음 난도로 가세요([캐릭터 성장](/growth/character/#경험치-패널티)).

**고행·순교에서 갑자기 녹아요.**
난도 패널티로 저항이 20·40씩 떨어집니다. 캐릭터 창에서 화염·번개 저항을 확인하고, 고행은 장비 저항 50%, 순교는 90% 이상을 목표로 맞추세요. 방어력도 몬스터 레벨에 대비해 효과가 떨어지므로 방어구를 정예형·전설형으로 바꾸세요.

## 장비

**좋은 장비를 주웠는데 장착 버튼이 안 눌려요.**
요구 레벨이나 힘·민첩이 모자랍니다. 장비 상세 아래에 빨간 글씨로 사유가 나옵니다. 능력치를 넣거나 힘 옵션 장비를 먼저 끼세요.

**입고 있는 장비가 빨간색이에요.**
재분배 등으로 요구치가 떨어져서 효과가 꺼진 상태입니다. 능력치를 다시 맞추면 돌아옵니다.

**가방이 가득 찼어요.**
던전에서는 장비를 골라 "버리기"를 두 번 누르면 버려집니다. 버린 장비는 되찾을 수 없습니다. 보석·룬·골드는 가방이 차도 주울 수 있습니다.

**룬을 넣었는데 룬워드가 안 돼요.**
세 가지를 확인하세요.
1. 장비가 **일반 또는 우수** 등급인가요? 마법 이상은 안 됩니다.
2. 소켓 수가 룬 수와 **정확히** 같은가요?
3. 룬을 **정해진 순서**대로 넣었나요?

틀렸다면 연금 도가니의 '소켓 비우기'(혼 룬)로 비울 수 있지만, 넣은 룬은 사라집니다.

**고유가 떨어져야 하는데 희귀가 나와요.**
고유·세트는 정해진 기반에서만 나오고, 아이템 레벨이 등장 레벨 이상이어야 합니다. 조건이 안 맞으면 희귀로 바뀝니다([고유·세트](/items/uniques-sets/)).

**고유 장비를 기반 승급하고 싶어요.**
고유·세트는 정해진 기반에 묶여 있어서 승급할 수 없습니다. 예전 버전에서는 승급이 되었다가 그 뒤 저장이 모두 실패하는 버그가 있었고, 지금은 조합 대상에서 빠집니다.

## 저장

**"저장 데이터가 손상되었거나 호환되지 않습니다"가 떠요.**
원본은 지우지 않고 그대로 두었습니다. 살리고 싶다면 개발자 도구 콘솔에서 `localStorage.getItem('ashen-covenant-save')`를 복사해 두세요. 새 게임을 두 번 누르면 덮어쓰고 처음부터 시작합니다.

**예전 버전 저장은요?**
이어하기를 누르면 자동으로 새 형식으로 옮겨집니다. 원본은 `ashen-covenant-save-v2-backup`에 남습니다([저장과 데이터](/help/save-data/#버전-2-저장-옮기기)).
