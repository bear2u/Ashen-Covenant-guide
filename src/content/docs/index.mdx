**ASHEN COVENANT** · 한 명의 마검사 · 세 가지 기술 트리 · 여섯 구역의 던전

재의 성약(Ashen Covenant)을 처음 시작하는 모험가부터 다음 난도에 도전하는 플레이어까지, 출정에 필요한 정보를 모았습니다. 조작법을 익히고, 나에게 맞는 기술과 장비를 골라 재의 대주교에 도전하세요.

## 처음 한다면

1. [시작하기](/start/getting-started/): 첫 접속과 첫 출정
2. [조작](/start/controls/): PC와 휴대폰 조작
3. [게임 흐름](/start/game-flow/): 거점 → 던전 → 보스 → 다음 난도
4. [빌드 가이드](/builds/guide/): 무엇을 찍고 무엇을 입을지

## 용어

| 용어 | 뜻 |
| --- | --- |
| 거점 | 꺼지지 않는 성화. 상인·보관함·제단·출정문이 있는 안전 지대 |
| 난도 | 순례(1) · 고행(2) · 순교(3) |
| 의지 | 기술을 사용할 때 소비하는 자원 |
| 잔불 | 낙인 찍힌 적을 베면 쌓이는 표식. 원형 참격이 소비해 화염 피해와 파열을 일으킴 |
| 몬스터 레벨 | 방마다 정해진 레벨. 체력·피해·경험치·드롭 아이템 레벨을 결정 |
| 아이템 레벨 | 아이템이 떨어진 곳의 몬스터 레벨. 붙을 수 있는 옵션 등급과 소켓 수를 결정 |
| 품질 레벨 | 기반 장비마다 정해진 레벨. 이 레벨 이상의 아이템 레벨에서만 그 기반이 떨어짐 |
| 기반 | 장비의 바탕 종류(예: 성기사 장검). 기본형·정예형·전설형 3단계 |
| 등급 | 낡은·일반·우수·마법·희귀·세트·고유·제작·룬워드 |
| 하드 포인트 | 직접 투자한 기술 포인트. 장비 +기술은 포함하지 않음 |
