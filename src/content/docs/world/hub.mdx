## 잿빛 수녀 (상인)

E로 말을 걸면 구매·도박·판매 탭이 있는 창이 열립니다.

### 구매

- 진열품은 8개입니다: 일반 3개, 마법 5개(마지막 1개는 반지).
- 아이템 레벨은 **캐릭터 레벨**과 같습니다. 그래서 레벨이 오르면 더 좋은 기반과 옵션이 진열됩니다.
- 거점에 들어올 때마다(귀환·이어하기) 새로 굴립니다.
- 가격은 판매가의 5배입니다([아이템 기본](/items/basics/#가격)).
- 이미 산 진열품은 다시 살 수 없습니다(아이템 ID가 기록됨).
- 마법 진열품은 등급 판정을 거치지 않고 강제로 마법이 되므로, 필요한 옵션(저항, 공속 등)을 확실히 노릴 때 좋습니다.

### 도박

종류를 골라 골드를 내면 **무작위 장비**를 받습니다(d2data `difficultylevels` 도박 열 참고).

| 항목 | 값 |
| --- | --- |
| 고를 수 있는 종류 | 검, 갑옷, 투구, 장갑, 장화, 허리띠, 반지, 부적 |
| 아이템 레벨 | 캐릭터 레벨 −5 ~ +4 (1~45) |
| 기반 | 그 아이템 레벨에서 나올 수 있는 그 종류의 기반 중 하나 |
| 등급 확률 | 고유 1% · 세트 3% · 희귀 12% · 마법 84% |
| 가격 | `(80 + 캐릭터 레벨 × 35) × 종류 배율` |

| 종류 | 배율 | 레벨 10 | 레벨 20 | 레벨 30 | 레벨 40 |
| --- | --- | --- | --- | --- | --- |
| 검 | 1.3 | 559 | 1,014 | 1,469 | 1,924 |
| 갑옷 | 1.2 | 516 | 936 | 1,356 | 1,776 |
| 투구 | 1.0 | 430 | 780 | 1,130 | 1,480 |
| 장갑·장화·허리띠 | 0.9 | 387 | 702 | 1,017 | 1,332 |
| 반지 | 1.6 | 688 | 1,248 | 1,808 | 2,368 |
| 부적 | 1.8 | 774 | 1,404 | 2,034 | 2,664 |

- 고유·세트에 당첨돼도 그 기반에 맞는 고유·세트가 없으면 희귀로 바뀝니다. 고유가 있는 기반은 [고유·세트](/items/uniques-sets/)에서 확인하세요. 반지·부적은 고유·세트 후보가 있어서 도박 효율이 좋습니다.
- 가방이 가득 차 있거나 골드가 모자라면 버튼이 비활성화됩니다.
- 자동 플레이에서는 남는 골드로 반지·부적을 도박해 저항과 생명을 채웠습니다.

### 판매

- 판매 탭에서 가방의 장비를 누르면 바로 팔립니다. 버튼 아래에 판매가가 보입니다.
- 장비 창에서도 거점이라면 "판매" 버튼이 나옵니다.
- 잠긴 장비와 착용 중인 장비는 팔 수 없습니다.

## 보관함

- 60칸입니다. 거점에서만 열 수 있습니다.
- 가방 쪽 아이템을 누르면 보관함으로, 보관함 쪽 아이템을 누르면 가방으로 옮겨집니다.
- 세트 부위, 나중에 쓸 룬워드 기반, 능력치가 모자라 아직 못 입는 장비를 맡겨 두세요.

## 성약의 제단 (연금 도가니)

d2data `cubemain`의 조합을 이 게임에 맞게 옮긴 곳입니다. 재료 주머니의 보석·룬과 가방의 장비를 씁니다.

- 재료가 갖춰진 조합만 "가능"으로 표시됩니다.
- 장비가 필요한 조합은 가방에서 장비를 먼저 고릅니다. 잠긴 장비는 쓸 수 없습니다.
- 재료는 조합이 성공할 때만 빠집니다.
- 보석을 "아무 종류"로 요구하는 조합은 **가장 낮은 등급부터** 자동으로 골라 씁니다.
- 재료 주머니가 99개로 가득 찬 종류는 승급 결과를 받을 수 없어 조합이 막힙니다.

### 재료 승급 (27종)

| 조합 | 재료 | 결과 |
| --- | --- | --- |
| 보석 승급 (16종) | 같은 보석 3개 | 같은 종류 한 등급 위 보석 1개 |
| 룬 승급: 잿~혼 (6종) | 같은 룬 3개 | 다음 번호 룬 1개 |
| 쇠 → 피 | 쇠 룬 3 + 깨진 이상 보석 1 | 피 룬 |
| 피 → 별 | 피 룬 3 + 보통 이상 보석 1 | 별 룬 |
| 별 → 달 | 별 룬 3 + 무결점 이상 보석 1 | 달 룬 |
| 달 → 서약 | 달 룬 3 + 완벽한 보석 1 | 서약 룬 |
| 서약 → 종언 | 서약 룬 3 + 완벽한 보석 1 | 종언 룬 |

### 장비 조합 (7종)

| 조합 | 대상 장비 | 재료 | 결과 |
| --- | --- | --- | --- |
| 마법 재굴림 | 마법 | 보통 등급 보석 3개(종류 무관) | 같은 기반의 새 마법 아이템. 아이템 레벨 = **캐릭터 레벨** |
| 희귀 재굴림 | 희귀 | 무결점 보석 3개(종류 무관) | 같은 기반의 새 희귀 아이템. 아이템 레벨 유지 |
| 소켓 뚫기 | 소켓 없는 일반·우수, 소켓 가능 기반 | 숨 룬 + 빛 룬 + 무결점 이상 보석 1 | 소켓 1개 ~ 최대(무작위) |
| 소켓 비우기 | 소켓에 무언가 박힌 장비 | 혼 룬 1 | 소켓을 모두 비움. 박혀 있던 보석·룬은 사라짐. 룬워드도 풀림 |
| 기반 승급 | 기본형·정예형 장비 (고유·세트 제외) | 쇠 룬 + 뼈 룬 + 무결점 이상 보석 1 | 같은 종류의 한 단계 위 기반. 옵션 유지 |
| 피의 제작 | 마법 검·장갑·반지·부적 | 피 룬 + 보통 이상 홍옥 | 제작 아이템: 생명 흡수 3~6%, 처치 시 생명 3~6 + 무작위 옵션 1~3개 |
| 폭풍 제작 | 마법 검·장갑·반지·부적 | 빛 룬 + 보통 이상 황옥 | 제작 아이템: 번개 1~(10~25), 번개 피해 10~20% + 무작위 옵션 1~3개 |

#### 재굴림 참고

- 아이템 ID와 잠금 상태는 그대로이고, 내용만 새로 굴립니다.
- 마법 재굴림은 캐릭터 레벨로 다시 굴리므로, 낮은 레벨에서 주운 좋은 기반을 지금 레벨의 옵션으로 바꿀 수 있습니다.

#### 기반 승급 경로

같은 종류의 다음 단계 기반 중, 공격 속도 성향이 같은 것을 우선합니다.

| 원래 기반 | 승급 후 |
| --- | --- |
| 순례자의 장검, 기사검 | 성기사 장검 |
| 결투 세검 | 그림자 세검 |
| 처형인의 대검 | 잿불 대검 |
| 성기사 장검 | 성흔 장검 |
| 폭풍 기사검 | 종언의 검 |
| 그림자 세검 | 서약자의 세검 |
| 잿불 대검 | 뇌정 대검 |
| 그을린 가죽 외투, 사슬 갑주, 녹슨 철 흉갑 | 순례자의 판금 |
| 순례자의 판금, 진홍 사슬 갑주, 재의 흉갑 | 대성당 수호 판금 |
| 쇠 투구, 거친 대투구 | 성가대 가면 |
| 성가대 가면, 서약의 관 | 대주교의 관 |
| 가죽 장갑, 쇠 건틀릿 → 성기사 건틀릿 → | 서약자 건틀릿 |
| 가죽 장화, 강철 각반 → 행군 장화 → | 순례자의 각반 |
| 끈 허리띠 → 판금 허리띠 → | 성흔 허리띠 |

- 방어구의 방어 값은 원래 범위 안의 위치를 유지한 채 새 범위로 옮겨집니다(예: 원래 범위 최댓값이었으면 새 범위에서도 최댓값).
- 소켓 수는 유지되며, 새 기반의 최대 소켓보다 많으면 줄어듭니다.
- 요구 레벨·힘·민첩이 새 기반 값으로 올라갑니다. 승급 전에 요구치를 확인하세요.
- 고유·세트 장비는 기반이 정해져 있어서 승급할 수 없습니다(조합 목록에서 고를 수 없음).
- 반지·부적과 전설형은 승급할 수 없습니다.

#### 제작 아이템

- 아이템 레벨 = `캐릭터 레벨 ÷ 2 + 원래 아이템 레벨 ÷ 2`(반올림)
- 무작위 옵션은 희귀에 붙을 수 있는 옵션 중에서 고르며, 고정 옵션과 같은 계열(흡수·처치 생명 / 번개 추가·번개%)은 나오지 않습니다.
- 이름은 희귀처럼 두 단어이고 주황색입니다.
