2026-10-25에 연결된 Runway 워크스페이스에서 이 게임용으로 생성했습니다. 외부 게임의 음원이나 이미지를 가져온 것이 아닙니다. 생성 프롬프트, 모델 작업 종류와 작업 ID는 `art/runway/manifest.json`에 보존했습니다.

## 적용한 리소스

| 종류 | 파일 | 게임에서 사용하는 위치 |
| --- | --- | --- |
| 타이틀 배경 | `public/assets/ui/runway/cathedral-title.jpg` | 재의 성약 첫 화면의 폐허 성당 |
| 거점 음악 | `public/assets/audio/runway/hub.mp3` | 거점과 보스 처치 후 |
| 탐험 음악 | `public/assets/audio/runway/dungeon.mp3` | 던전 진입 |
| 보스 음악 | `public/assets/audio/runway/boss.mp3` | 대주교 전투 시작 |
| 환경음 | `public/assets/audio/runway/cathedral.mp3` | 세 장면 공통 성당 바람·화로 |
| 검 휘두르기 | `swing.mp3` | 기본 공격, 원형 참격 |
| 타격 | `hit.mp3`, `heavyHit.mp3` | 검 적중, 강타 |
| 원소 | `zap.mp3`, `boom.mp3` | 번개, 폭발, 화염 낙인 |
| 회피·회복 | `dodge.mp3`, `potion.mp3` | 회피, 회복약 |
| 전리품 | `rareDrop.mp3` | 희귀 보상, 레벨업 |
| 환경·몬스터 | `gate.mp3`, `bossRoar.mp3`, `enemyDie.mp3` | 성문, 보스 포효·함성, 적 사망 |

효과음 파일도 모두 `public/assets/audio/runway/`에 있습니다. 클릭·거절·골드·피격 경고 등 나머지 소리는 기존 합성음을 유지합니다. 플레이 중 사용하는 바닥·벽·스프라이트는 기존 에셋을 유지했습니다.

## 재생과 용량

- 음악 3곡은 원본 기준 약 143초·178초·149초입니다. 끝과 처음을 2초 교차 처리해 반복 재생합니다.
- 음악과 환경음은 HTML 미디어 스트리밍으로 재생하고 WebAudio의 공통 음량·컴프레서에 연결합니다. 장면 전환에는 짧은 페이드가 있습니다.
- 짧은 효과음 11개는 동시 3개씩 로딩·디코딩하며, 최초 로딩 중에는 합성 효과음을 사용합니다. 전투 효과음은 최대 16개 동시 재생으로 제한합니다.
- 전체 런타임 추가 용량은 약 7.96 MB입니다. 원본은 `art/runway/source/`에 별도 보관하며 배포 빌드에는 포함하지 않습니다.
- 배포 후 Runway 로그인·API·비밀키 없이 재생됩니다. 첫 게임 시작 입력에서 오디오를 활성화합니다.
- 탭이 숨겨지면 음악과 오디오 컨텍스트를 멈추고, 복귀 후 사용자 입력으로 재개합니다. 기존 전체 음량 설정에 음악과 효과음 모두 반응합니다.
- 재가공: 프로젝트 폴더에서 `python3 art/runway/prepare.py`를 실행합니다. ffmpeg와 ffprobe가 필요합니다.

## 검증

- 기존 규칙 단위 테스트 130개 통과.
- `tests/e2e/audio.mjs`: 데스크톱·모바일 에뮬레이션에서 실제 오디오 그래프 신호, 파일 디코딩, 거점→던전→보스 음악 전환, 빠른 전환 정리, 동시 효과음 제한, 음소거·복구, 파일 404 시 대체 동작 검증.
- 결과: `artifacts/runway-audio-validation.json`, 화면: `artifacts/runway-title.jpg`, `artifacts/runway-title-mobile.jpg`.
- 실제 iOS·Android 기기 스피커 청취는 미실행입니다.
- 정적 빌드는 `dist/`에 생성합니다. Three.js를 포함한 JS 묶음의 500 kB 크기 경고가 있으며 빌드 오류는 아닙니다.
